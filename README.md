# Hotel Booking Cancellation Prediction using Artificial Neural Networks

### Project Overview
This project predicts whether a hotel booking will be cancelled or not using an Artificial Neural Network (ANN). The model is trained on hotel booking data by applying data preprocessing, feature engineering, handling class imbalance, and deep learning techniques.

The main objective of this project is to help hotels reduce revenue loss caused by booking cancellations and improve reservation management.

---

### Problem Statement
Hotel booking cancellations create major challenges for the hospitality industry such as:

- Revenue loss
- Poor room allocation
- Inefficient resource management
- Customer management issues

This project uses Machine Learning and Deep Learning techniques to predict booking cancellations before the actual check-in date.

---

### Objectives
- Predict hotel booking cancellations accurately
- Analyze important booking features
- Build a robust ANN model
- Improve prediction performance using preprocessing techniques
- Handle imbalanced data effectively

### Machine Learning Workflow

#### 1. Data Collection
The dataset contains hotel booking information such as:

- Hotel type
- Lead time
- Arrival details
- Meal type
- Market segment
- Room type
- Deposit type
- Customer type
- Booking changes
- Previous cancellations
- Special requests
- Reservation status

---

#### 2. Data Preprocessing
The following preprocessing steps were performed:

- Handling missing values
- Removing unnecessary columns
- Encoding categorical features
- Feature scaling using StandardScaler
- Power Transformation
- Train-Test Split

---

#### 3. Exploratory Data Analysis (EDA)
EDA was performed to understand:

- Booking patterns
- Cancellation trends
- Feature relationships
- Correlation between variables

Visualization libraries such as Matplotlib and Seaborn were used.

---

#### 4. Handling Imbalanced Data
Since booking cancellation data is imbalanced, imbalance handling techniques were applied to improve model performance.

---

#### 5. ANN Model Building

### ANN Architecture

- Hidden Layers

The model was trained and optimized to achieve better prediction accuracy.
